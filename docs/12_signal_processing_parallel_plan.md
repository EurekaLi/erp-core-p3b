## 3. S2：冻结紧凑特征定义，预计40列

选固定后部ROI四通道：CPz、Pz、PO3、PO4，沿用既有协议，不依据分类测试结果重新选电极。
模型基线只用trial级信号；条件平均用于描述，不把条件平均复制给每条trial。

### 3.1 ERP幅值：12列

四通道各取三个闭区间窗口的平均电位：200–300ms、300–600ms、600–800ms。
300–600ms为既有主要窗口，前后窗为预先声明的补充特征；端点掩码使用实际256Hz时间轴，
数据字典记录每窗实际采样点数。单位µV。

不以单trial峰值潜伏期为第一版核心特征：短噪声峰很容易被误解释为认知时延。
不根据全体差异热图或显著簇再挑“最好”的窗口；原已看过的全体ERP图不是训练折内特征选择证据。

### 3.2 频带功率：12列

四通道各取刺激后0–800ms的theta[4,8)、alpha[8,13)、beta[13,30]功率。
采用Welch PSD、Hann窗、nperseg=128、noverlap=64、nfft=128，固定2Hz频率间距。
以声明的离散bin边界规则求和乘以Δf，结果是粗离散频带近似，不能说alpha恰好由理想8–13Hz滤波得到。
PSD使用µV²/Hz，积分近似为µV²，分类特征采用log10(max(power,1e-12µV²))。
这个固定下限只防止log(0)，不作为数据质量阈值。

零填充可以让频率轴更密，但不增加真实频率分辨率；本计划不借它假装精细频带测量。
0.8秒内Welch可用平均段较少，功率只是粗略单trial特征；它不是刺激锁定的Morlet时频结果。
beta上沿受既有30Hz低通影响，所有模型比较时注明这一限制。

### 3.3 离散小波：16列

在四通道的完整257点短epoch上做db4、level=5、symmetric边界DWT。
实现时检查`pywt.dwt_max_level(257, db4.dec_len)`，不得把短序列强行分解更深。
每通道取D5、D4、D3三个系数块的相对能量，再取一个系数块能量熵，共4列。

标称尺度约为D5=4–8Hz、D4=8–16Hz、D3=16–32Hz。
它们不是理想滤波器，也不与Welch的theta/alpha/beta完全一一对应。
相对能量分母包含A5及D5…D1全部系数块；熵为六块能量比例的归一化Shannon熵。
边界延拓下系数能量不应被无条件当作精确物理能量守恒；固定定义和边界模式即可形成可复现特征。

验收：每列有名称、算法、通道、窗/尺度、单位和边界定义；全部7207行有限；不因某个特征异常悄悄删除trial。

## 4. S3：数据清单与固定划分，和深度学习共同完成

这是两线唯一必须先共同冻结的接口。

- trial_id来自subject与原trial_index，不来自当前行号；
- label固定Standard=0、Target=1；
- 外层5折按受试者划分，测试每人只出现一次；
- 每折外层训练组内固定验证受试者；
- 每折检查训练/验证/测试类别计数；
- 保存明确的受试者列表、trial_id清单、种子、算法、数据hash。

若采用分组分层算法，要记录它只能近似平衡标签，不能为了完全平衡把同一人拆开。
sub-006、sub-010等低Target人数继续保留，只解释不稳定性，不查看测试分数后追加排除。

传统模型、EEGNet、CBraMod共用同一训练/验证/测试受试者名单。
第一版传统模型即使不需要早停，也先只用共同训练部分拟合，避免隐含增加训练数据量。
数据版本变化需要另存划分，不能拿旧划分混合新trial缓存。

## 5. S4：Logistic Regression和增量对照

第一版固定一个低成本分类器：

```text
StandardScaler → LogisticRegression
C=1.0，class_weight=balanced，solver=lbfgs，max_iter=2000
```

StandardScaler必须在训练部分fit，随后transform验证/测试。
class_weight=balanced根据训练标签估计，不拿全体类别比例预设。
标签、行为正确性、刺激码、受试者编号不是特征列。

固定三组对照：ERP 12列；ERP+功率24列；ERP+功率+小波40列。
使用相同划分和评价，比较每个特征族的增量价值，先不同时扩展LDA/SVM等。

PCA不是第一版40列模型的必需步骤。后续可作为可选对照：
`StandardScaler → PCA(0.95) → LogisticRegression`，每折仅在训练数据fit。
若要调C，只用共同验证受试者或训练组内分组交叉验证，不在外层测试集调参。

验收：保存每条外层测试trial的概率/预测、每折模型配置、训练类别权重、收敛信息；
遇到不收敛明确诊断，不能偷偷只保留分数好的折。

## 6. S5：评价、解释与项目闭环

主报告为39名受试者各自指标的等权汇总，避免trial多的人主导结果。
同时提供全部OOF测试trial合并指标，明确它和受试者等权平均不是同一量。

至少报告balanced accuracy、ROC-AUC、Average Precision、Target precision/recall/F1和混淆矩阵。
AP明确命名为Average Precision，不能与梯形积分PR-AUC混称一个数。
缺少某类时指标不定义就记缺失并解释，不强行补0；主数据每人两类均非空。

主阈值先固定0.5；若另做阈值优化，必须由验证集决定并记录，不能看测试召回率再调。
置信区间按受试者bootstrap，而不是把相关trial当独立观测重采样。
模型比较采用相同受试者的成对指标；第一轮一个固定种子跑通，深度学习多种子随后补齐。
置换检验和更多模型作为后续稳健性扩展，不阻塞基础闭环。

标准化后的LR系数反映模型权重，不等同于脑源强度或因果贡献。
相关特征间系数可能重新分配；解释时结合特征族增量、稳定性和既有ERP生理结果。

最终交付：证据索引/受试者汇总表、特征数据字典、trial特征表、划分清单、OOF预测、
39人指标与CI、模型比较图、局限性和复现命令。
