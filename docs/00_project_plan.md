# 项目计划与阶段验收标准

当前进度：阶段1--5已完成，下一步进入阶段6“时频与特征工程”。Phase 5
的正式数值、图形解释和限制见 `docs/07_p3b_results.md`。

## 阶段 1：环境与研究协议

目标是让任何人在一台新机器上按照同一份配置创建环境，并理解本项目回答什么问题。

验收标准：

- `environment.yml` 能创建 Python 3.11 环境；
- `python -m pip install -e .` 成功；
- README 说明数据来源、任务、方法边界和复现方式；
- 预处理参数有唯一配置来源。

## 阶段 2：数据下载与结构验证

下载 P3 范式的 40 名受试者原始 BIDS 数据，验证参与者表、通道表、事件表、采样率、单位和电极位置。

验收标准：

- 原始文件校验完整；
- 能读取至少两名受试者；
- 明确 Target/Standard 对应的事件码；
- 明确反应正确性和行为事件如何编码；
- 记录原始参考方式、线噪频率和 EOG 通道。

## 阶段 3：自动质量控制

建立受试者级 QC，先观察再冻结阈值。输出原始波形、PSD、通道方差、平直通道、异常高频功率、事件计数和缺失信息。

验收标准：

- 每名受试者生成结构一致的 QC 文件；
- 坏道判定可以追溯到指标；
- 不因查看分类测试结果而修改 QC 阈值。

## 阶段 4：预处理

建立两个信号分支：0.1–30 Hz 的 ERP 分析分支，以及适合稳定拟合 ICA 的 1–40 Hz 临时分支。完成重参考、坏道插值、ICA、epoch、基线校正和伪迹 trial 剔除。

验收标准：

- 原始数据保持只读；
- 插值通道和 ICA 排除成分均有日志；
- 清洗前后 PSD、EOG 锁定平均和 trial 保留率可比较；
- 每个受试者能够稳定生成 epochs。

## 阶段 5：经典 P3b 基线

比较 Target 与 Standard 的 ERP，报告 P3b 平均幅值、峰值潜伏期、效应量和头皮分布。

验收标准：

- 预先定义主要通道和时间窗；
- 同时展示个体和群体结果；
- 报告配对检验、效应量和置信区间；
- 使用时空 cluster permutation 作为探索性补充。

## 阶段 6：时频与特征工程

提取 ERP、频带功率、Morlet 时频和离散小波特征。PCA 用于训练折内降维，ICA 只用于源分离和伪迹处理，两者职责不混淆。

验收标准：

- 生成可审计的 trial 级特征表；
- 每列特征的单位和计算窗口有数据字典；
- PCA 不接触验证或测试数据；
- 比较不同特征族的增量价值。

## 阶段 7：传统分类基线

使用 Logistic Regression、LDA 和 SVM 区分 Target/Standard。正式结果采用按受试者分组的交叉验证。

验收标准：

- 同一受试者不跨训练折和测试折；
- 报告 balanced accuracy、ROC-AUC、AUPRC、F1；
- 报告每名受试者结果和置信区间；
- 使用标签置换检验评估是否显著优于机会水平。

## 阶段 8：结果复现与作品化

整理可复现命令、核心图表、误差分析、方法限制和简历表述，使项目既能被技术面试官复核，也能清楚展示信号处理能力。

验收标准：

- 从空环境能够运行到最终结果；
- 汇总数据质量、trial 保留率和模型误差来源；
- 区分预先定义分析与探索性分析；
- GitHub 包含复现命令、核心图表、限制和简历描述。
