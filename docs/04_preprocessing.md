# ERP CORE P3b 预处理：原理、实现与结果

本文记录从连续原始 EEG 到可分析 epoch 的全部处理决策。目标不是把波形“变得好看”，
而是在尽量保留 P3b 神经信号的前提下，控制低频漂移、高频噪声、眼电、坏道和极端 trial，
并让每一次删除都有配置或表格可追溯。

## 1. 本阶段的输入与输出

输入包括：

- 40 名受试者的 EEGLAB `.set/.fdt` 连续数据；
- BIDS `events.tsv` 与 `channels.tsv`；
- 原始QC冻结的人工坏道：`sub-035/PO3`、`sub-039/Oz`；
- 行为刺激—反应配对结果。

正式输出包括：

- `data/interim/preprocessing/final/sub-XXX/*_ica.fif`：每人的 ICA 模型；
- `data/processed/epochs/final/*_epo.fif`：清理后的 MNE Epochs；
- `results/preprocessing/final/subject_preprocessing.csv`：受试者级汇总；
- `results/preprocessing/final/epoch_qc.csv`：每个行为有效 trial 的峰峰值和剔除状态；
- `results/preprocessing/final/ica_components.csv`：每个 ICA 成分与3个EOG通道的相关；
- `results/preprocessing/final/subject_review_candidates.csv`：需要人工决定是否排除的受试者；
- `reports/figures/preprocessing/final/`：每人的滤波、ICA、epoch及ERP检查图。

原始数据始终只读。所有中间结果都可由配置和脚本重新生成。

## 2. 为什么先标坏道，而不是先做 ICA

`sub-035/PO3` 与 `sub-039/Oz` 在40人原始QC中同时满足方差离群和低通道相关，人工复核后
登记在 `configs/manual_qc.yaml`。先把它们写入 `raw.info['bads']` 有两个作用：

1. 坏道不会参与平均参考，避免一个极端通道污染所有正常通道；
2. 坏道不会参与 ICA 拟合，避免 ICA 浪费成分解释单个电极故障。

插值放在 ICA 校正之后。插值不是“猜回真实测量值”，而是根据邻近电极的空间分布估计一个
连续值，因此后续报告中仍要保留坏道历史。插值结束后再次计算平均参考，使新生成的插值通道
与其余 EEG 处于相同参考系。最终文件中 `bads` 为空，但坏道来源保存在配置和受试者汇总表中。

## 3. 两个滤波分支

同一份原始信号建立两个副本，原因是 ERP 与 ICA 对高通滤波的需求不同。

| 分支 | 频带 | 用途 | 原因 |
|---|---:|---|---|
| ERP 分支 | 0.1–30 Hz | 最终 epoch 和 ERP | 0.1 Hz 高通尽量保留 P3b 的慢变化，30 Hz 低通压制肌电和高频噪声 |
| ICA 分支 | 1–40 Hz | 只用于估计 ICA 分解 | 1 Hz 高通减少慢漂移对 ICA 的支配，使眼动成分更稳定 |

这里使用零相位 FIR 滤波。零相位表示滤波器前后对称应用，不把 P3b 峰整体向前或向后移动；
代价是它只能用于离线分析，不能假装成实时系统。

没有另加 60 Hz 陷波。两个分支的低通上限分别为30和40 Hz，已经低于60 Hz；重复使用陷波
会增加不必要的频响畸变。每张QC图左上角同时显示原始与处理后 Pz 功率谱，可直接检查30 Hz
以上是否被衰减，以及原始60 Hz峰是否消失。

## 4. 降采样：1024 Hz 到 256 Hz

采样率从1024 Hz降到256 Hz。根据奈奎斯特关系，256 Hz采样率能够表示的最高频率为128 Hz，
高于本项目30 Hz的ERP分析上限。MNE在重采样时执行抗混叠低通，因此高频成分不会简单折叠到
低频。降采样把数据点减少为四分之一，显著降低 ICA、epoch 和后续时频分析的内存与时间成本。

256 Hz 下每个采样点间隔约3.906 ms。P3b 是数百毫秒尺度的成分，因此这个时间分辨率足够；
如果研究几十毫秒内的高频振荡，则不能直接沿用该设置。

## 5. 平均重参考

电压只能表示两个位置之间的电势差，EEG 不存在绝对的“零电位”。平均参考将每个时刻的所有
有效 EEG 通道均值减去每个通道：

```text
x_ref(channel, t) = x(channel, t) - mean_good_EEG(x(:, t))
```

它使结果不再依赖采集时使用的单个参考电极，并适合当前覆盖全头的30通道布局。坏道在第一次
平均中被排除；坏道插值之后再计算一次平均参考。

## 6. ICA 的原理和本项目规则

ICA 把多通道观测写成若干统计上尽量独立的源的线性混合：

```text
X ≈ A @ S
```

`X` 是通道×时间数据，`S` 是独立成分时间序列，`A` 描述每个成分投影到头皮的空间分布。
眼球转动产生的电场通常在额部最强，并与 EOG 同步，因此可以在成分空间识别，而不是直接删除
包含眨眼的整段连续记录。

本项目使用 FastICA，并采用以下保护条件：

- 在1–40 Hz、256 Hz、平均参考数据上拟合；
- 保留能够解释99%数据方差的主成分，而不是固定成分数；
- 拟合时每隔2点取样，减少相邻采样高度重复造成的计算开销；
- 随机种子固定为42，保证可复现；
- 最多迭代3000次；
- 成分与 `HEOG_left`、`HEOG_right`、`VEOG_lower` 中任一通道的绝对相关必须达到0.70；
- 每人最多自动删除3个成分；
- 保存每个成分的相关系数和被删成分的头皮地形图。

三人试运行曾使用0.50阈值。`sub-006/ICA002` 的相关为0.53，但其地形不呈典型额部眼电模式，
因此正式阈值保守地收紧到0.70。这个规则宁可残留少量眼动，也避免把相关但可能具有神经来源的
成分自动删掉。最终40人共删除26个强EOG相关成分。

首轮中 `sub-011` 在1000次迭代内未收敛。把上限提高到3000后，它在2760次收敛；其余受试者
也全部收敛。最终结果中没有未收敛的 ICA。

## 7. 行为筛选和事件分段

只有满足以下条件的刺激进入 epoch：

- 刺激是 Target 或 Standard；
- 第一个配对反应码表示正确；
- 不存在缺失反应、多次反应或小于150 ms的预期反应标记。

40人共有8000个刺激 trial，其中7588个通过该行为规则。行为筛选发生在振幅剔除之前，两种
删除原因因此不会混在一起。

每个刺激切成 `−0.2～0.8 s` 的 epoch，并用 `−0.2～0 s` 均值做基线校正。基线校正相当于
从该 epoch 的每个时间点减去刺激前均值，使条件比较关注刺激引发的变化，而不是持续直流偏置。

## 8. epoch 峰峰值阈值如何确定

对每个行为有效 epoch，先在每个 EEG 通道内计算最大值减最小值，再取30个通道中的最大值：

```text
epoch_PTP = max_channel(max_time(x) - min_time(x))
```

这比只检查 Pz 更严格，因为任一通道的巨大瞬态噪声都可使 trial 失效。单位统一转换为微伏。

在 `sub-006、sub-017、sub-035` 的518个试运行 epoch 中：

- 中位数：71.5 µV；
- 95%分位数：183.1 µV；
- 200 µV阈值剔除约4.1%的长尾 trial。

因此正式配置冻结为 `200 µV`。这不是所有 EEG 数据都适用的通用常数；它来自本数据集、当前
滤波频带、参考方式和epoch长度。改变任一条件后都应重新查看分布。

## 9. 40人正式结果

| 指标 | 结果 |
|---|---:|
| 原始刺激 trial | 8000 |
| 行为有效、进入分段 | 7588 |
| 超过200 µV被剔除 | 527 |
| 最终保留 epoch | 7061 |
| 最终 Target epoch | 1264 |
| 最终 Standard epoch | 5797 |
| 自动删除 ICA 成分 | 26 |
| 插值坏道 | sub-035/PO3；sub-039/Oz |
| ICA 未收敛受试者 | 0 |

作为事件对齐和处理方向的生理合理性检查，按受试者先平均后，在 Pz 的300–600 ms窗口得到：

- Target 平均幅值：5.732 µV；
- Standard 平均幅值：2.195 µV；
- Target−Standard 平均差：+3.537 µV；
- 40/40 名受试者的差值均为正。

这不是正式统计检验，但说明条件码没有反转、事件没有整体错位，预处理后仍能观察到预期的
顶叶 P3b 方向。正式推断需要在下一阶段定义测量窗口、效应量和统计模型。

## 10. 需要人工决定的受试者

自动规则把 epoch 剔除率超过20%或 ICA 有效维数低于10者列为复核候选，不直接排除：

| 受试者 | 剔除率 | 额外原因 | 当前状态 |
|---|---:|---|---|
| sub-009 | 52.43% | ICA仅3个成分，说明少数大方差源支配数据 | 待人工决定 |
| sub-025 | 20.60% | 略高于20%阈值 | 待人工决定 |
| sub-030 | 64.06% | 大量epoch超过200 µV | 待人工决定 |
| sub-039 | 58.08% | Oz已插值，但许多epoch整体仍接近或超过阈值 | 待人工决定 |

不要仅因“剔除率高”立刻删除受试者。下一步应查看噪声是否集中于特定通道/时段、两条件剩余
trial 是否足够、排除前后组水平效应是否发生异常变化，并进行包含/排除候选者的敏感性分析。
