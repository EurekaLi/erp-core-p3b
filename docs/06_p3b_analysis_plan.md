# 阶段 5：经典 P3b 分析计划

## 1. 本阶段回答什么问题

本阶段只回答一个主要问题：在完成质量控制和预处理后，Target 相比 Standard 是否在 Pz 电极的 300--600 ms 时间窗产生更正向的 P3b 平均幅值？

这是后续时频分析和机器学习的信号有效性基线。若经典 ERP 效应无法稳定复现，直接进入复杂特征或分类容易得到难以解释的结果。

## 2. 输入数据与分析总体

正式主分析使用：

- 输入目录：`data/processed/epochs/adjudicated`；
- 受试者：39 人；
- 主分析排除：`sub-030`；
- 保留 epoch：7207 个，其中 Target 1286 个、Standard 5921 个；
- 每个受试者先在条件内平均，再进入群体统计。

统计单位必须是“受试者”，而不是 7207 个 epoch。大量 trial 来自同一个人，它们并非彼此独立；若把 trial 当作独立样本，会产生伪重复并夸大有效样本量。

## 3. 预先冻结的主要分析

主要分析在查看本阶段统计显著性之前固定为：

| 项目 | 固定设置 | 原因 |
|---|---|---|
| 条件对比 | Target - Standard | 直接表示目标刺激相对标准刺激的电位变化 |
| 主要电极 | Pz | P3b 的中心顶叶测量位置，且 39 人数据均包含该通道 |
| 时间窗 | 300--600 ms | 用窗口平均降低单点噪声和峰值抖动的影响 |
| 主要指标 | 窗口平均幅值，单位 µV | 比最大峰值更稳定，适合跨受试者比较 |
| 统计检验 | 双侧配对 t 检验 | 每名受试者同时具有 Target 和 Standard 两个条件 |
| 效应量 | Cohen's dz | 与配对设计一致，用差值的标准差进行标准化 |
| 不确定性 | 95% bootstrap 置信区间 | 同时展示效应估计的不确定程度 |
| 显著性水平 | 0.05 | 在运行主要统计前固定 |

配置的唯一来源是 `configs/erp_analysis.yaml`。`features.yaml` 中原有的 `POz` 已移除，因为实际数据没有该通道。

主要检验只做一次，不根据 P 值改用其他电极、时间窗或单侧检验。波形上看见的其他效应可以报告，但必须标记为探索性结果。

## 4. 次要和探索性分析

### 4.1 次要指标

在 Pz 的同一 300--600 ms 窗口计算：

- 峰值幅值：窗口内最大正电位；
- 峰值潜伏期：最大正电位出现的时间；
- 有符号面积：时间窗内电位积分；
- 后部 ROI：`CPz、Pz、PO3、PO4` 的平均结果。

峰值容易受高频噪声和采样点波动影响，因此不能替代平均幅值成为主结果。Wilcoxon 符号秩检验仅作为分布稳健性检查，不能因为它的 P 值更小才选择报告。

### 4.2 头皮分布

分别绘制 Target、Standard 和 Target - Standard 在 300--600 ms 的平均头皮图。头皮图用于回答效应是否呈合理的空间分布，不用于从所有电极中挑出“最显著”的新主通道。

### 4.3 时空 cluster permutation

在 0--800 ms、全部 EEG 通道上运行时空 cluster permutation，作为探索性补充。它用于定位连续的时间—空间效应并控制大量相邻比较，不用于反向修改已经冻结的 Pz、300--600 ms 主分析。

## 5. 执行顺序

1. **输入完整性检查**：确认 39 个 epoch 文件可读、事件名一致、采样率和通道集合一致，并生成分析清单。
2. **受试者级 ERP**：每人分别平均 Target 和 Standard trial，保存条件 ERP 与差异波。
3. **主要测量表**：每人输出两个条件的 Pz 平均幅值及 Target - Standard 差值。
4. **主要统计**：计算配对 t 检验、Cohen's dz、均值差和 95% bootstrap 置信区间。
5. **次要结果**：计算峰值、潜伏期、面积、后部 ROI 和 Wilcoxon 稳健性检查。
6. **群体可视化**：绘制条件波形、差异波、个体配对图、差值分布和头皮图。
7. **探索性统计**：运行时空 cluster permutation，并把结果与主分析分开保存。
8. **QC 敏感性分析**：比较 39 人主分析、额外排除 `sub-025` 的 38 人版本，以及加回 `sub-030` 的 40 人版本。
9. **结果报告**：生成表格、图形、参数清单和一段可直接用于 README/简历的结果摘要。

## 6. 应该重点检查的图

### 群体 ERP 波形

横轴是刺激后的时间，纵轴是电位 µV。应同时显示 Target、Standard 和差异波，并在 300--600 ms 标出主窗口。重点看：

- 刺激前基线是否接近 0 µV；
- Target 在主窗口是否整体比 Standard 更正；
- 效应是持续的窗口差异，还是由一个尖锐噪声峰造成；
- 置信区间是否极宽，是否被少数受试者主导。

### 个体配对图和差值分布

每条线连接同一受试者的两个条件。重点看多数人是否方向一致，以及总体效应是否由一两个极端值推动。差值分布和 Q-Q 图用于检查配对 t 检验对异常值是否敏感。

### 个体差异波热图

每行一个受试者，每列一个时间点。它能显示 P3b 是否在多数人中出现、潜伏期是否存在明显个体差异，以及某人是否在整个时段呈异常大幅值。

### 头皮图

重点看 300--600 ms 的 Target - Standard 差值是否具有连贯空间结构。单个边缘电极的孤立极值更可能提示残余噪声，不应被解释为稳定的脑电效应。

## 7. 敏感性分析的判定原则

正式结论以 39 人裁决版为准。38 人和 40 人版本只回答“个案 QC 决定是否足以改变结论”。判断时比较：

- Target - Standard 的方向是否一致；
- 效应量变化是否明显；
- 置信区间是否大幅移动；
- 结论是否完全依赖某一名受试者。

不能用三个版本中 P 值最小的一个替代主结果。如果显著性发生变化，应如实报告效应估计和不确定性，并解释它对数据质量决策的敏感程度。
