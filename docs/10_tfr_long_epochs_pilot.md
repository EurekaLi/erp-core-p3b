## 2. 从连续信号重建的处理顺序

```text
原始EEGLAB EEG/EOG
 -> 按既有通道类型与montage读取，登记已裁决坏道
 -> TFR分支：0.1--40 Hz零相位FIR滤波
 -> 降至256 Hz
 -> 在有效EEG上平均参考（坏道暂不参与）
 -> 验证冻结ICA的通道顺序、参考、采样率和排除成分
 -> 应用冻结ICA，不重新fit
 -> 若有坏道，插值并重新对全部EEG计算平均参考
 -> 只按Phase 4裁决保留事件提取[-2.1,2.1] s
 -> 不减电压baseline，不自动执行振幅剔除
 -> 审计保护支持、外围上下文及小批功率baseline
 -> 独立保存长epochs与QC记录
```

ICA可以理解为通过多通道之间的混合关系分离成分。它的矩阵并不认识“哪个数组列现在代表哪个电极”，
因此应用时通道顺序、参考关系必须与拟合时相符，不能把任意长epoch直接交给模型。
本项目原ICA在1--40 Hz连续分支上拟合；本次应用到0.1--40 Hz分支，但不重新估计分解矩阵。
MNE允许将已经拟合的ICA应用到对应信号；基线和滤波兼容性仍由项目显式验证。
[MNE ICA文档](https://mne.tools/stable/generated/mne.preprocessing.ICA.html)

pilot三人都没有登记插值坏道；后续全体仍需覆盖sub-009、sub-035、sub-039的插值路径。
sub-025仍使用冻结ICA成分0和2，不因长窗异常擅自多删成分。

## 3. 为什么单独做ERP复现对照

正式TFR分支的40 Hz低通、不减电压baseline，与旧ERP分支不同，因此不能要求两者逐点相同。
为了查处理错误，本程序额外重建一条**完全沿用Phase 4参数的ERP对照**：0.1--30 Hz、256 Hz、
相同ICA、参考、短窗和电压baseline。比较全部trial、全部EEG/EOG采样点，而不只看Pz平均图。

预先固定最大绝对误差容差为0.001 µV；实际三人的最大误差均约0.000008 µV，远低于容差。
这支持事件没有偏移、ICA和参考顺序正确，而不是证明长窗已没有伪迹。

保存长窗使用FIF的double载荷，不覆盖旧ERP文件。
实际重读发现即使double载荷也有约10^-5 µV量级的小误差，与有限精度通道校准头一致；
因此重跑验证使用物理单位容差，不要求二进制逐位相等。已添加专门的FIF往返测试。

## 4. “保护支持”是什么，为什么不能只检查画图范围

主分析显示[-0.2,0.8] s，但小波功率计算会使用显示时刻两侧的信号。
本次6--30 Hz完整核支持最大半宽为0.39453125 s；再把功率baseline的支持合并，
所有主分析实际可能使用的输入范围为：

```text
保护支持 = [-0.9921875, 1.1953125] s
完整长窗 = [-2.1015625, 2.1015625] s
```

因此一个异常发生在−0.7秒，即使不在正式图里，也可能影响基线或早期功率；
发生在+1.0秒也可能进入较晚功率计算。
仅发生在+1.8秒的异常没有进入本次主分析完整核支持，但可能影响2--5 Hz探索分支。
“仅外围异常”不是所有分析都可以忽略，只是不能据此自动否定6--30 Hz主展示窗。

程序分别计算：

- `full_max_ptp_uv`：整个长窗的最大通道峰峰值；
- `display_max_ptp_uv`：正式数值展示范围内的峰峰值；
- `baseline_support_max_ptp_uv`：功率baseline输入支持内的峰峰值；
- `display_support_max_ptp_uv`：时频展示输入支持内的峰峰值；
- `protected_max_ptp_uv`：合并保护支持内的峰峰值；
- 对应超限通道数，以及最大偏离的位置。

峰峰值就是“窗口内最大值−最小值”。窗口越长，捕获更大起伏的机会越多，
所以原1秒ERP窗的200 µV规则不能未经验证就变成2.19秒保护窗的正式自动剔除规则。
这里仅借用200 µV定位需要查看的候选；它既不证明一定有伪迹，也不支持直接提高到500 µV放行。

### 5.2 从最严重波形观察到什么

候选“最强保护通道”的分布：sub-001为F8 13次、FP2 2次、PO8 1次；
sub-006为FP2 10次、FC4 5次、O1 1次；sub-025为FP2 19次、FP1 8次。
这个计数每trial只取一个最大通道，不是每个通道的全部异常次数。

- **sub-001**：最严重候选trial 190，F8保护PTP约260.3 µV；波形含较强快速起伏。
  同一trial旧ERP最大PTP约176.7 µV，新40 Hz分支正式展示PTP约206.9 µV。
  提示滤波上限变化也可能暴露更多快速活动，不只由扩展长度引起。
- **sub-006**：trial 43，FP2保护PTP约383.7 µV，能看到跨秒的持续斜坡；旧短窗PTP约165.2 µV。
  短窗合格与长支持异常并不矛盾。该形态需要进一步结合EOG/原始连续信号判断来源。
- **sub-025**：trial 103，FP1保护PTP约691.9 µV，FP1/FP2出现很大的缓慢变化；
  旧短窗PTP约177.3 µV。这不自动证明应该多删ICA成分或把FP1/FP2登记为全局坏道。

目前这些是幅度与形态证据，不能仅凭波形认定是眼动、肌电、电极漂移还是低频神经活动。
不同trial的长窗相互重叠，59个候选也不代表59次彼此独立的异常事件。
清单同时记录原始记录时间，方便下一轮合并同一连续异常片段进行复核。

## 6. 小批Morlet数值检查证明了什么

每人选8个trial，包括两条件的若干trial以及最严重保护候选，执行6--30 Hz复数Morlet：

```text
数组形状 = 8 × 30 EEG通道 × 25频率 × 1077时间点
```

检查复数系数与功率为有限值，baseline平均功率严格为正，正式展示范围dB为有限值。
不使用任意epsilon掩盖0分母；ITC与条件统计尚未实施。

三人最小baseline平均功率约为1.39×10^-12、4.83×10^-13、8.83×10^-13 V²，
对应批次全部通过数值检查。最小值本身不是“信号质量优良”的指标，也不意味着485个trial的baseline都已经逐一验证。
此次只证明所选8-trial批次可以正确完成计算；大伪迹同样可能产生有限、正数的功率。

## 7. 实测内存和保存规模

使用psutil每20 ms采样本进程RSS，并在关键阶段加采样点；包括加载、ERP对照重建、
TFR长窗重建、小批复数/功率/dB计算和作图。BLAS线程限制为1，MNE TFR `n_jobs=1`。

最新验证轮次的三人耗时约3.19、2.62、2.67秒，磁盘缓存和机器负载会影响这个数值。
内存是绝对进程RSS，不是整个电脑或其他进程内存；20 ms采样可能遗漏很短暂的峰值，
也不是未来全体TFR统计的峰值保证。进程内存缓存会影响后续受试者的起始RSS。

三个double FIF分别约51.69、36.46、43.81 MiB，总计约131.96 MiB。
目前只保存长窗信号、metadata和QC图，不保存完整四维单trial时频数组。
本机已有psutil/threadpoolctl，未新建环境或安装软件；已把直接依赖补入`environment.yml`便于其他机器复现。

```powershell
Set-Location -LiteralPath 'D:\AILearning\project_for_offer\erp-core-p3b'

& 'D:\LearnWareSoft\CondaEnvs\erp-core-p3b\python.exe' scripts/07_build_tfr_epochs.py --stage pilot --verify-existing

# 仅生成候选分页图和清单，不重新处理连续信号。
& 'D:\LearnWareSoft\CondaEnvs\erp-core-p3b\python.exe' scripts/07_build_tfr_epochs.py --review-only
```

复核清单是程序生成的候选表，`manual_decision=pending`不意味着机器已裁决。
再次`--review-only`会重建该候选表，因此人工结论应另存版本化决策文件，不在会被重建的输出表中作为唯一记录。
本轮没有实现自动消费人工决定；后续需将正式复核决定接入门控，不能直接编辑`run_summary.json`把false改true。

只有pilot技术、资源和伪迹门控通过，且配置哈希一致，才允许`--stage final`。
当前有59个未决候选，执行该选项会在读取全体连续信号前拒绝；不会绕过检查继续运行。
已提供独立测试验证这个行为。

## 10. 下一步需要作出的决定

建议先逐trial复核这59个保护候选，并结合EOG、相邻连续片段、通道分布和频谱判断：

1. 哪些只是更长区间内的慢变化，哪些是确实影响目标频带/功率baseline的异常；
2. 哪些属于同一连续异常片段，不应重复当作多次独立异常；
3. 是否保留当前0.1--40 Hz分支，或先做与0.1--30 Hz分支的盲态质量对照；
4. 是否需要正式新增坏段、局部通道修复或TFR专用trial剔除规则，及其对两条件计数的影响。
