## 2. 从epoch开始理解：它不是一种新的信号

epoch就是以某个事件为0秒，从连续EEG上取出的一段真实信号。
例如刺激发生在记录的第100秒，[-0.2, 0.8] s epoch对应记录的99.8--100.8秒。
“长TFR epoch”不是另一批实验，也不是新的标签，而是对同一刺激取更长的片段。

| 比较项 | Phase 4/5 ERP epochs | Phase 6专用TFR epochs |
|---|---|---|
| 核心问题 | 刺激后电压随时间如何变化 | 某频率的功率与相位如何随时间变化 |
| 时间窗 | 约[-0.2, 0.8] s | [-2.1, 2.1] s，正式展示仍为[-0.2, 0.8] s |
| 256 Hz下点数 | 257 | 1077，约为原来的4.19倍 |
| 输入物理量 | EEG电压 | EEG电压，卷积后才成为复数系数/功率/相位 |
| 基线处理 | 电压减去刺激前均值 | 长epoch不减电压基线；计算功率后做dB归一化 |
| 滤波分支 | 0.1--30 Hz | 计划0.1--40 Hz，主分析频率仍为6--30 Hz |
| trial身份 | 已通过行为与伪迹裁决 | 只从同一裁决名单回溯，不重新加入已删除trial |
| ICA | 已拟合并冻结 | 复用冻结模型和排除成分，不在长epoch上再次拟合 |
| 额外两侧数据的作用 | ERP测量一般不需要这么长的上下文 | 为卷积提供真实上下文，计算后裁掉不解释的边缘 |

为什么不能把旧epochs补零变长？补零只增加数组长度，不恢复刺激前后真实的脑电。
为什么不直接把长窗都画成正式结果？远离0秒的部分主要是计算上下文，其中还可能包含相邻刺激。

### 2.1 电压基线与功率基线不是一回事

ERP电压基线：对一个通道的电压减去刺激前平均电压，单位仍为V（作图常转µV）。
TFR功率基线：在每个频率上，用刺激后功率相对于刺激前参考功率的比例归一化：

```text
功率dB = 10 × log10(当前功率 / 基线平均功率)
```

0 dB表示与该参考均值相同，正值表示较强，负值表示较弱。
这个参考不是“没有脑活动”，也不是独立静息态；它是在连续任务中的刺激前参考。
MNE的`logratio`本身不等于乘10后的功率dB，后续程序必须按明确公式实施。

### 2.2 不同分支为什么不必逐点相同

两支复用相同的trial、ICA和坏道决定，但滤波上限和电压基线不同，重叠时间窗内的波形不应被要求逐点相等。
后续应单独做一项“同参数ERP复现”检查：使用相同滤波、参考和电压基线，再验证重叠波形。
这能检查处理顺序/事件偏移是否正确，不能用来否定正式TFR分支中有意改变的参数。

## 3. 小波为什么需要左右上下文

Morlet可以理解为“带高斯包络的一小段振荡”。在时刻t估计某频率的活动，不只使用t这个电压点，
还会加权使用t前后的信号。这个操作叫卷积；因此标在0秒的功率不等于仅由0秒电压算出。

周期数规则固定为：

```text
n_cycles(f) = clip(f / 2, 3, 10)
```

MNE默认宽度关系为`σ = n_cycles / (2πf)`，核近似延伸到左右各5σ。
`n_cycles/f`不是完整核长度。[MNE Morlet官方说明](https://mne.tools/stable/generated/mne.time_frequency.morlet.html)

本程序实际调用本机MNE生成核，而不是只套近似公式：

| 频率 | 周期数 | 核点数 | 核首末点跨度 | 单侧支持长度 |
|---|---:|---:|---:|---:|
| 2 Hz | 3 | 611 | 2.3828125 s | 1.19140625 s |
| 3 Hz | 3 | 407 | 1.5859375 s | 0.79296875 s |
| 4 Hz | 3 | 305 | 1.1875 s | 0.59375 s |
| 5 Hz | 3 | 245 | 0.953125 s | 0.4765625 s |
| 6 Hz | 3 | 203 | 0.7890625 s | 0.39453125 s |
| 30 Hz | 10 | 135 | 0.5234375 s | 0.26171875 s |

“跨度”按首末采样点之差计算，核点数等于跨度×采样率+1。
完整支持长度不等于有效时间分辨率：高斯尾部权重很小，中心权重更大。
审计另存包络FWHM（半高全宽）；例如2 Hz约0.562 s，而不是所有±1.191 s信号都被等权平均。

本次采用“完整支持不能触及当前/邻近刺激”的保守检查。
支持范围相交只能证明存在潜在时间混合，不能估计实际污染的大小；不相交也不证明上一刺激ERP尾部完全消失。

## 4. 程序具体检查了哪些内容

1. **确认分析人群**：裁决版39人、排除sub-030；全体trial数须等于7207。
2. **逐trial对齐**：通过`subject + trial_index`匹配原始刺激；验证刺激时间、刺激码、条件、降采样事件点和行为有效性。
3. **核对已有决定**：Target/Standard计数须与Phase 4裁决汇总一致，冻结ICA文件须存在。存在性检查不等于应用兼容性检查。
4. **检查连续记录边界**：按256 Hz整数采样网格检查窗口两端，不能越过最后一个实际采样点。
5. **检查断点/坏段注释**：识别BAD和boundary，包括持续时间为0的断点；普通刺激和反应注释不算坏段。
6. **计算真实邻居**：相邻刺激来自所有原始刺激，包括后来被QC删除的trial；删除一个trial并不会删除当时实际呈现的刺激。
7. **检查小波支持**：分别检查基线、展示窗和300--600 ms测量窗；分开报告核是否装得下、是否跨边缘、是否触及邻近刺激。
8. **估算数组规模**：分开计算电压epochs、float64功率、complex128系数和8-trial批次工作量。
9. **记录复现信息**：配置SHA256、库版本、数据路径、运行时间和受试者名单。

程序不调用`get_data()`加载EEG，不重新做ICA，不据条件显著性选参数。
配对时间窗复用既有行为规则（最短反应150 ms、最长1600 ms），避免审计悄悄改变trial定义。

### 5.3 为什么原2 Hz基线不适合直接冻结

以[-0.8,-0.2] s基线为例，在256 Hz网格上实际取样为[-0.796875,-0.203125] s。
2 Hz核的单侧支持为1.19140625 s，因此所有基线中心对应的卷积输入范围合起来为：

```text
[-0.796875 - 1.19140625, -0.203125 + 1.19140625]
= [-1.98828125, +0.98828125] s
```

这同时说明两个独立问题：

- 原[-1.5,2] s epoch左侧不够，基线卷积缺少真实数据；
- 即使加长到[-2.1,2.1] s，标作“刺激前基线”的功率仍可能使用当前刺激后约988 ms内的数据。

另外，约97.47%的trial，其2 Hz基线完整支持范围覆盖前一刺激的呈现区间；
约97.50%的trial，其2 Hz正式展示/300--600 ms测量支持范围触及下一刺激起点。
这些是**支持范围相交比例**，不是实测的“功率污染百分比”，不能据此说97%的脑电无效。

因此不能通过“再加长epoch”解决全部问题，更不能用剔除所有有邻居的trial来人为制造一个新任务样本。
2 Hz并非在本数据中完全不可计算；这里只限制它作为当前刺激特异、刺激前基线归一化主结果的解释。

## 6. 本次冻结的方案与理由

### 6.1 主分析参数

| 参数 | 固定值 |
|---|---|
| 采样率 | 256 Hz |
| 长epoch | [-2.1, 2.1] s |
| 正式展示 | [-0.2, 0.8] s |
| 主要测量时间 | [0.3, 0.6] s，沿用Phase 5，不是全部TFR只能看这一窗 |
| 频率网格 | 6--30 Hz，步长1 Hz |
| 周期数 | clip(f/2, 3, 10) |
| Morlet zero_mean | true |
| 电压baseline | 不执行 |
| 功率baseline | [-0.6, -0.4] s；10×log10功率比 |
| TFR工作方式 | 一人一次、每批8 trial、n_jobs=1 |
| 初步内存规划预算 | 2 GiB；必须在下一阶段实测试运行 |

6 Hz核的单侧支持为0.39453125 s。
该基线在采样网格上为[-0.59765625,-0.40234375] s，其完整输入支持为[-0.9921875,-0.0078125] s，
终点仍在刺激前。正式展示窗就近端点为[-0.19921875,0.80078125] s，完整支持最晚为1.1953125 s，早于最短下一刺激起点1.3994 s。
6--30 Hz全部频率均通过边缘检查；基线支持与前一刺激呈现、展示支持与下一刺激起点的相交比例均为0。

这里的6 Hz是**在固定周期规则、这组基线、1 Hz网格和保守完整支持准则下**的选择，
不是所有EEG研究都必须从6 Hz开始。5 Hz在同一基线下会越过0秒；改变周期数或基线还可能得到其他方案。
本次不搜索更多组合去追求条件显著性，也不把200 ms基线当成很多独立周期：这些功率点高度相关，
后续需要检查每trial基线功率的数值稳定性，尤其分母接近0的情况，不能悄悄添加任意epsilon。

为什么不直接用也合格的[-1.1,1.3] s？紧凑窗适合只做6--30 Hz；
采用统一[-2.1,2.1] s可同时为2--5 Hz探索保留完整真实上下文，不必再次重建一套窗口。
新增上下文不是额外独立样本，不增加统计样本量。若之后确有资源约束，可以记录一次全体统一的协议修订。

### 6.2 低频探索的边界

2--5 Hz只计算未做上述刺激前归一化的功率，单独标记为探索性；原始功率来自V输入，通常标为V²而非PSD的V²/Hz，
其绝对值还受小波归一化约定影响，不直接等同于频谱密度。
该分支不能被称为刺激特异的delta/theta ERD/ERS，不能精确声称活动从某毫秒开始，不能进入主分类特征。
群体探索应先做受试者内汇总，不能把所有trial合并当作独立受试者。

主分析频带标签为高theta[6,8)、alpha[8,13)、beta[13,30] Hz；并非完整theta[4,8] Hz。
原计划的delta主分析已撤回。离散小波DWT是另一个有不同边界与滤波特性的分析，不能用它绕过本次限制而把低频系数自动解释成纯当前刺激活动。

## 7. 内存规模：为什么必须分批

数组元素数可按以下公式估算：

```text
电压epoch = trial数 × EEG通道数 × 时间点数
完整功率 = trial数 × EEG通道数 × 频率数 × 时间点数
float32每元素4 bytes，float64每元素8 bytes，complex128每元素16 bytes
1 GiB = 2^30 bytes
```

39人7207个trial、30 EEG通道、1077点：

| 内容 | 主要数组载荷 |
|---|---:|
| 全体长epoch电压，float64 | 1.735 GiB |
| 全体长epoch电压，float32 | 0.867 GiB |
| 6--30 Hz完整功率，float64，25频率 | 43.373 GiB |
| 6--30 Hz完整复数系数，complex128 | 86.746 GiB |
| 2--30 Hz完整功率，float64，29频率 | 50.313 GiB |
| 2--30 Hz完整复数系数，complex128 | 100.626 GiB |

FIF文件还包含元数据和保存精度约定，不能把上表直接当作实际磁盘大小。
同时保留功率和复数数组时内存相加；若把上述所有数组一起放入内存会更大。

本程序还估算“3份原始float64连续数组 + 一人的long epochs + 8-trial复数和功率批次”。
主分析候选的最大单人模型值约0.601 GiB；2--30 Hz探索规划约0.624 GiB。
这是主要数组载荷模型，不是实测峰值；FFT缓存、ICA/PCA工作区、Python对象、库实现和临时复制未完全计入。

所以下一阶段仍应先实测3人，不应把0.601 GiB当作运行时内存保证。
程序按人顺序处理，在批内累积条件汇总和紧凑特征，不持久保存完整四维单trial TFR。
