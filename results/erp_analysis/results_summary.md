# Phase 5 P3b 结果摘要

## 主要分析

39人裁决版数据中，Pz 300--600 ms 的 Target - Standard 平均差为 3.486 µV，95% bootstrap CI [2.738, 4.323]，t(38)=8.476，p=2.732e-10，Cohen's dz=1.357。

## 稳健性检查

Wilcoxon符号秩检验：W=0.000，p=3.638e-12，配对秩二列相关=1.000。
