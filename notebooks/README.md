# Notebooks

Notebook 仅用于数据探索、结果解释和面试展示。经确认的正式算法应迁移到 `src/erp_core_p3b/`，以便测试、批处理和复现。

计划中的 Notebook：

1. `01_dataset_exploration.ipynb`：数据结构、事件、通道和原始波形；
2. `02_preprocessing_qc.ipynb`：滤波、坏道、ICA 和 epoch QC；
3. `03_erp_statistics.ipynb`：P3b 曲线、头皮图和统计；
4. `04_time_frequency_features.ipynb`：时频、小波与 PCA；
5. `05_model_interpretation.ipynb`：分类结果和超图解释。
